# OSINT Academy V14

Production-ready static package.

## Includes
- V13 content and existing features preserved
- expanded OSINT methodology
- privacy engineering and threat modeling
- Tor Browser educational module
- expanded tools directory
- interactive SVG Data Visualizer Pro with local persistence and JSON export
- glossary and FAQ
- master learning roadmap
- responsive navigation and mobile layout
- external CSS/JS assets
- manifest, favicon, robots.txt, sitemap.xml, 404.html

Use only for lawful, ethical research with public information.


## V15 production checklist
- Replace `https://example.com` in `sitemap.xml` and `robots.txt` with the final public URL.
- GitHub Pages: publish from `main` / root or use the included static files.
- `.nojekyll` is included so the site is served as plain static files.
- `sw.js` adds basic offline caching after the first visit.
- `privacy.html` and `terms.html` are included.
- Visualizer supports JSON import/export, SVG export, selection and deletion.
- All core JavaScript is dependency-free.
